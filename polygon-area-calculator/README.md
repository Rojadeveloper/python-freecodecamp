Polygon Area Calculator
Proyecto realizado como parte del curso de Python de freeCodeCamp.

El objetivo del proyecto es crear una calculadora de propiedades geométricas mediante las clases Rectangle y Square, utilizando programación orientada a objetos y herencia.

Funcionalidades
Crear rectángulos y cuadrados.
Establecer el ancho y la altura de un rectángulo.
Modificar el lado de un cuadrado manteniendo iguales sus dimensiones.
Calcular el área de una figura.
Calcular el perímetro.
Calcular la longitud de la diagonal.
Generar una representación visual de las figuras utilizando caracteres *.
Determinar cuántas veces una figura puede caber dentro de otra sin rotarla.
Mostrar la información de cada figura mediante una representación en cadena.
Conceptos practicados
Durante este proyecto practiqué:

Clases y objetos.
Constructores y atributos de instancia.
Herencia entre clases.
Sobrescritura de métodos.
Reutilización de código mediante super().
Métodos especiales (__init__ y __str__).
Operaciones matemáticas con el módulo math.
Bucles y manipulación de cadenas.
Cálculos geométricos.
Relaciones entre clases mediante la programación orientada a objetos.

Aprendizaje
Este proyecto me permitió practicar los fundamentos de la programación orientada a objetos y comprender cómo la herencia facilita la reutilización de código entre clases relacionadas.

También aprendí a sobrescribir métodos para adaptar el comportamiento de una clase hija y mantener las propiedades de un cuadrado, así como a implementar cálculos geométricos y representar figuras mediante texto.
