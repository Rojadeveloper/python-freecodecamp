# Proyecto 3 - Polygon Area Calculator

Proyecto realizado como parte del curso de Python de freeCodeCamp.

El objetivo de este proyecto es trabajar con rectángulos y cuadrados para calcular sus propiedades geométricas, utilizando clases y herencia en Python.

## Funcionalidades

- Crear rectángulos y cuadrados.
- Calcular el área, el perímetro y la diagonal de una figura.
- Modificar el ancho y la altura de un rectángulo.
- Cambiar el lado de un cuadrado manteniendo sus dimensiones iguales.
- Representar las figuras mediante caracteres `*`.
- Calcular cuántas veces cabe una figura dentro de otra sin rotarla.
- Mostrar las dimensiones de cada figura.

## Conceptos practicados

Durante este proyecto practiqué:

- Clases y objetos.
- Constructores y atributos de instancia.
- Herencia entre clases.
- Sobrescritura de métodos.
- Uso de `super()` para reutilizar el constructor de la clase padre.
- Métodos especiales (`__init__` y `__str__`).
- Operaciones matemáticas con el módulo `math`.
- Bucles y cadenas de texto.
