# Budget App

Proyecto realizado como parte del curso de **Python de freeCodeCamp**.

El objetivo del proyecto es crear una aplicación sencilla para administrar presupuestos mediante categorías, permitiendo registrar depósitos, retiros y transferencias entre categorías.

## Funcionalidades

* Crear categorías de presupuesto.
* Registrar depósitos.
* Registrar retiros.
* Consultar el saldo disponible.
* Comprobar si existe suficiente dinero antes de realizar un retiro.
* Transferir dinero entre categorías.
* Mostrar el historial de movimientos.
* Generar un gráfico con el porcentaje de gastos por categoría.

## Conceptos practicados

Durante este proyecto practiqué:

* Clases y objetos.
* Atributos de instancia.
* Métodos.
* Listas y diccionarios.
* Bucles y condicionales.
* Métodos especiales (`__str__` y `__iter__`).
* Validación de fondos disponibles.
* Manipulación de cadenas.
* Cálculos de porcentajes.
* Organización de datos mediante una estructura de `ledger`.

Este proyecto me permitió practicar programación orientada a objetos y comprender cómo diferentes métodos pueden trabajar juntos para administrar los datos de una categoría.
